# Архитектурные решения

| Решение | Почему | Более простая альтернатива | Когда пересмотреть |
|---|---|---|---|
| Агрегация в PostgreSQL | Карточки и CSV используют одни SQL-факты. GROUPING SETS считает итог, дни и показатели филиалов за текущий период. AVG даёт одинаковый вес каждому отзыву. | Расчёт в React потребовал бы отправлять историю всех разрешённых филиалов. Отдельный запрос для каждой строки таблицы увеличивал бы число обращений к БД. CSV использует ту же функцию SQL. | Измерять планы на фактических периодах, вводить партиции и предрасчёт при росте истории. |
| Общая область прав в SQL | Справочник, отчёт, CSV, отзывы и изменение статуса применяют предикат компании. При PATCH он входит в сам UPDATE. | Фильтрация готового массива оставила бы запись без такой гарантии. Для явного филиала нужен поиск внутри области, чтобы вернуть 404 даже за пустой период. | Добавить PostgreSQL RLS для независимой проверки на уровне БД. |
| JWT в cookie и окно входа в PostgreSQL | Cookie и JWT имеют один срок. Атомарное резервирование места до bcrypt ограничивает также параллельные запросы. | Счётчик в памяти короче, но обнуляется при рестарте и расходится между экземплярами. Для общей записи уже есть PostgreSQL. | Добавить отзыв сессий и лимит на входном прокси, при необходимости вынести счётчики в отдельное хранилище. |
| Снимок дня с upsert | Ключ филиала и даты защищает от дублей. Повтор с исправленными цифрами обновляет день в транзакции вместе с журналом. | DO NOTHING оставляет старую цифру. Тест считывает из базы 41 просмотр после исправления исходного значения 12. | Включить идентификатор источника в ключ, когда появится второй поставщик. |
| Ограниченные синхронные повторы импорта | Один учебный источник иногда задерживает ответ или возвращает 429/5xx. Четыре попытки с таймаутом укладываются в запрос администратора. | Единственная попытка теряет период при кратком сбое. Счётчик попыток записывается вместе с результатом. | Длинные задания перенести в очередь с лимитом параллелизма по источнику. |
| Общие URL-фильтры для отчёта и сравнения | Оба филиала загружаются через существующий маршрут дашборда. Адрес сохраняет фильтры при обновлении страницы. График и доступная таблица строятся из одних UTC-дат. | Отдельный endpoint сравнения дублировал бы проверку области и расчёты. Два компонента выбора сведены в один, название филиала формируется одинаково во всех разделах. | Для десятков одновременных рядов оценить групповой запрос. |
| Курсор отзыва по устойчивому порядку | Время и уникальный id задают следующую страницу при одинаковом времени. Якорь курсора ищется только в текущей области доступа. | OFFSET сдвигает страницы при поступлении новых отзывов. Числового id достаточно для поиска точного времени в БД, включая доли секунды. | При горизонтальном разделении данных включить в курсор ключ маршрутизации. |
| Проверять поведение на трёх уровнях | Jest проверяет SQL и права на реальной PostgreSQL, Vitest — компоненты и выравнивание рядов, Chromium — браузер и скачанный файл. | Один браузерный сценарий не выявит независимую ошибку в API или сохранении. Фиксированные данные двух компаний и контрольные поломки показывают, какую регрессию ловит тест. | Выдавать независимые базы группам параллельного CI. |

На 500 филиалах хронологический индекс отзывов снизил чтение страницы со 124 до 11 блоков. Для фильтра рейтинга и статуса планировщик сохранил прежний индекс. Сид, SQL, методика и таблица замеров приведены в [README](README.md).

В React страницы собирают виджеты и сценарии, запросы React Query принадлежат хукам, а каждая сущность хранит запрос и ключ кеша в своём `api`. Для выборки данных ключ включает текущего пользователя и фильтры. Публичные интерфейсы слайсов явно перечисляют импортируемые сущности. Зависимости между слоями проверяет ESLint. [Слои Feature-Sliced Design](https://feature-sliced.design/docs/reference/layers)

Material UI 6.5 задаёт компоненты, Emotion обслуживает их стили, а `@mui/icons-material` даёт пиктограммы навигации и метрик. Общая тема задаёт Inter, основной цвет `#6765F2` и обе палитры. MUI сохраняет ручной выбор и следует настройке устройства в системном режиме. Два поднабора Inter загружены из Google Fonts и поставляются вместе с лицензией в `app/fonts`. Страница открывается и в сети без доступа к CDN. Day.js приводит границы периода и даты отзывов к UTC. [Inter в Google Fonts](https://fonts.google.com/specimen/Inter) · [Тема Material UI 6](https://v6.mui.com/material-ui/customization/css-theme-variables/configuration/) · [UTC в Day.js](https://day.js.org/docs/en/plugin/utc)

Prisma управляет схемой и параметрами SQL. Для Prisma 6.19.3 закреплены исправленные версии `effect` и `deepmerge-ts` из конфигурации CLI. При обновлении Prisma нужно пересмотреть эти две записи overrides. TypeScript оставляет алиасы `@/...` в выходном JavaScript, поэтому `tsc-alias` разрешает их при сборке. Vitest использует jsdom и Testing Library.

Nginx с непривилегированным пользователем отдаёт собранный фронт и проксирует API. Для браузера у страницы и API один адрес.
